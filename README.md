## <img src="https://media.giphy.com/media/LnQjpWaON8nhr21vNW/giphy.gif" width="28"> &nbsp;Proyek Pilihan

### 🏭 &nbsp;Sistem Industri & Manufaktur

Sistem yang berjalan di lantai produksi. Bagian tersulitnya bukan aplikasinya —
tapi **menyambungkan perangkat keras ke web**: sensor lewat MQTT, kartu RFID,
scanner, lengan robot, sampai CCTV.

| Proyek | Ringkas | Integrasi & Stack |
| --- | --- | --- |
| **Machine Health Monitoring (Steel)** | Pemantauan kesehatan mesin pabrik baja | `MQTT` · Laravel · MySQL · Linux |
| **Digital Checksheet System (WWT)** | Checksheet digital menggantikan kertas | `MQTT` · `Cronjob` · Laravel · Firebase |
| **Traceability Welding System** | Pelacakan proses las per unit produksi | `Robot` · Laravel · MySQL |
| **EQC Polymer & Mold Change** | Kendali mutu & pergantian mold | `RFID` · Laravel · MySQL |
| **EQC Machining NP** | Kendali mutu proses machining | `RFID` · Laravel · MySQL |
| **Real-Time Production Line Monitoring** | Data lini produksi langsung dari mesin | `CCTV` · `Multi-DB` · Laravel · Firebase |
| **Factory Insight** | Monitoring injection molding & die change | `Scanner QR` · Laravel · Firebase |
| **Cutting Tool Management** | Manajemen umur pakai cutting tool | `Scanner` · Laravel · Firebase |
| **Machine Health & Tank Monitoring (WWT)** | Pemantauan mesin & tangki instalasi air | Laravel · MySQL · Linux |
| **E-Maintenance Casting** | Perawatan mesin casting | `PivotTable` · Laravel · MySQL |
| **Toscast Communicator** | Aplikasi desktop komunikasi mesin | `Socket` · C# · .NET |
